# Linger releases

Installers and update files for [Linger](https://github.com/quicodomingo/linger-releases/releases), a desktop app for your Instagram direct messages.

Download the latest version from [Releases](https://github.com/quicodomingo/linger-releases/releases/latest). Installed apps update themselves.

Linger is not in any way affiliated with nor endorsed by Instagram (Meta) or any of its subsidiaries.
